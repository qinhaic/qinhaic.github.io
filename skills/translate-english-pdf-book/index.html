英文 PDF 全书中译 v2.0

translate-english-pdf-book · 把长篇英文书或双栏论文做成可校验、可续做的中文学习译稿

Codex Skill

用途

将英文 PDF 书籍完整翻译为简体中文，按章节持续保存，并交付经过漏译、术语、结构、排版与逐页渲染检查的 DOCX、PDF、TXT 或 Markdown。适合学术专著、双栏期刊论文（APA 样式）以及带注释、参考文献和索引的长篇非虚构书。

v2.0 新增：双栏/多栏坐标提取（extract_columns.py）、宋体 Word 生成（build_docx.py）、单文件译文源合并与参考文献保留原文（build_translations.py）、LibreOffice 无头渲染质检。

核心流程

  • 1. 来源核验：检查页数、加密、文本层、OCR 质量和文件指纹；判断版式，双栏走坐标分栏提取。
  • 2. 结构建档：识别章节和后置内容，为每个源段落建立稳定 ID。
  • 3. 术语冻结：代表性试译后确定术语表、专名规则和中文语体。
  • 4. 分章翻译：按语义边界分批，批批检查缺失、重复和空译文。
  • 5. 四遍复核：分别检查完整性、准确性、中文表达和全书连续性。
  • 6. 分类处理：注释核对编号，参考文献保留检索性，索引注明原版页码。
  • 7. 同源排版：从同一最终正文生成宋体 Word、PDF 与纯文本版本。
  • 8. 最终验收：渲染 PDF 逐页检查裁切、乱码、空白、漏章和格式分叉。

安装与调用

下载完整 Skill ZIP 查看 SKILL.md

安装后可以说：使用 $translate-english-pdf-book，把这本英文 PDF 完整翻译成中文学习版，给我 Word 和 PDF。

验证记录

v1.0：由《The Hidden Spring》395 页英文原书的全书翻译经验蒸馏而来，真实试跑完整提取 395 页并生成 3,174 个可追踪段落；漏段失败、跨页连续、章节合并和独立盲测均已通过。

v2.0：由 Baskin-Sommers 等 2014 两栏 APA 论文（11 页）实战验证——坐标分栏提取 183 段，全流程（提取→翻译→校验→宋体 Word→LibreOffice 渲染→文本层质检）端到端通过；macOS 无 SimSun 时渲染自动替换中文字体属正常。
