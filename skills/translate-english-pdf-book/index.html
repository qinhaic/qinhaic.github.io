英文 PDF 全书中译

translate-english-pdf-book · 把长篇英文书做成可校验、可续做的中文学习译稿

Codex Skill

用途

将英文 PDF 书籍完整翻译为简体中文，按章节持续保存，并交付经过漏译、术语、结构、排版与逐页渲染检查的 DOCX、PDF、TXT 或 Markdown。适合学术专著以及带注释、参考文献和索引的长篇非虚构书。

核心流程

  • 1. 来源核验：检查页数、加密、文本层、OCR 质量和文件指纹。
  • 2. 结构建档：识别章节和后置内容，为每个源段落建立稳定 ID。
  • 3. 术语冻结：代表性试译后确定术语表、专名规则和中文语体。
  • 4. 分章翻译：按语义边界分批，批批检查缺失、重复和空译文。
  • 5. 四遍复核：分别检查完整性、准确性、中文表达和全书连续性。
  • 6. 分类处理：注释核对编号，参考文献保留检索性，索引注明原版页码。
  • 7. 同源排版：从同一最终正文生成 Word、PDF 与纯文本版本。
  • 8. 最终验收：把全书逐页渲染，检查裁切、乱码、空白、漏章和格式分叉。

安装与调用

下载完整 Skill ZIP 查看 SKILL.md

安装后可以说：使用 $translate-english-pdf-book，把这本英文 PDF 完整翻译成中文学习版，给我 Word 和 PDF。
