# 英文 PDF 全书中译

把整书翻译视为可恢复、可审计的出版流水线。任何阶段都不得用“读起来顺”代替完整性验证。

## 输入与交付

- 输入：英文 PDF、目标读者/用途、中文风格偏好、期望格式；缺省为简体中文个人学习版，忠实而自然。
- 交付：全书 DOCX、PDF、TXT 或 Markdown；较长书同时交付分章版本、术语表、QA 报告和文件目录。
- 工作目录：使用当前任务的 `work/` 存放提取文本、分段、译稿与渲染图；只把最终文件放入 `outputs/`。不要覆盖原文件或既有译稿。

## 必须先读

开始前读取 [translation-guide.md](references/translation-guide.md)。遇到复杂注释、参考文献、索引、图表或 OCR 时，再读 [qa-checklist.md](references/qa-checklist.md) 和 [project-schema.md](references/project-schema.md)。

## 工作流

### 1. 建档与可翻译性检查

1. 确认文件可读、未加密、页数、语言、目录和文本层质量。
2. 使用本技能的 `scripts/extract_pdf_book.py` 建项目并提取 layout/raw 文本；扫描本交给 PDF/OCR 流程后重新检查。
3. 浏览封面、版权页、目录、正文开头/中段/结尾、注释和索引代表页，建立书籍结构。
4. 记录来源版本和 SHA-256；不要把未核实的网络版本混入。

完成标准：`project.json`、带页码标记的提取文本和初步结构齐全；乱码、缺页或 OCR 风险已处理或明确标注。

### 2. 结构化与术语准备

1. 把前言、章节、后记、附录、致谢、注释、参考文献、索引和卷末信息分别列入 `sections.json`。
2. 对 `extracted-pages-layout.txt` 运行 `scripts/segment_book_text.py` 生成稳定段落 ID；人工复核跨页断句、脚注混入、页眉页脚和断词。不要用 raw 版本做自动分段。
3. 从标题、目录、索引和代表章节建立术语表，至少包含英文、首选中文、允许变体、禁用译法和说明。
4. 先试译 2–4 个代表性片段：叙述、技术论证、引文/注释、图表说明各取一段；据此冻结风格和术语。

完成标准：每个源段落有唯一 ID 和所属页；章节边界可追溯；试译获得可复用规范。

### 3. 分章翻译

按章节和语义边界分批，不按固定 token 生硬截断。每批：

1. 同时提供全书定位、当前章摘要、术语表和相邻段落。
2. 保留段落 ID；逐段翻译，不摘要、不删节、不扩写、不把解释写进正文。
3. 保留数字、公式、图表编号、注号、专名、引文层级、URL/DOI；姓名首现可采用“中文名（英文名）”。
4. 将不确定项写入独立问题表，正文不凭空补全。
5. 每批完成立即运行 `scripts/validate_translation.py`；结构错误必须修复后才继续。

完成标准：源 ID 与译文 ID 一一对应；无空段、重复段、遗漏批次；术语和专名按冻结规则处理。

### 4. 章节级复核

进行四遍分离复核，避免一次“润色”同时破坏忠实度：

1. 完整性：段落、标题、注号、图号、数字和引用均对应。
2. 准确性：抽查长句、否定、限定词、因果关系、术语和代词指向。
3. 中文性：消除翻译腔、错误搭配和歧义，但不改变论证强度。
4. 连续性：检查跨段衔接、章节标题、注释编号和术语全书一致。

任何润色后重跑结构和保真检查。禁止只保留“润色版”而丢掉可追溯的初译。

### 5. 后置内容分类处理

- 注释：翻译说明性文字，保留编号和回指；逐节检查连续性。
- 参考文献：默认保留原文，仅统一明显的提取错误；不要翻译书刊名而破坏检索。
- 索引：翻译主题词，保留英文原版页码并明确说明页码指向原书。
- 图表：翻译标题和说明；公式、单位、坐标和图号保持可核验。

### 6. 合并与出版排版

1. 运行 `scripts/assemble_book_markdown.py` 生成全书 Markdown，并检查目录顺序。
2. 调用可用的文档技能生成 DOCX；统一中文字体、标题层级、首行缩进、行距、页眉页脚和分页规则。
3. 调用可用的 PDF 技能从最终 DOCX 或同一结构源生成 PDF，避免维护两套不同正文。
4. 加入“AI 辅助个人学习译稿、非正式出版物、学术引用以英文原版为准”等真实用途说明，不伪称授权译本。

完成标准：全书版与分章版内容同源；文件名、元数据和目录清楚；不存在丢字字体或格式分叉。

### 7. 渲染与最终验收

1. 按文档技能要求渲染 DOCX；按 PDF 技能要求把 PDF 全部页面转成图片。
2. 先检查封面、目录、每章首页、图表页、注释/参考文献/索引页和末页，再用接触表快速扫全书；异常页放大复查。
3. 运行文本 QA：页数、文件大小、可复制文本、目录顺序、段落计数、注释连续性、残留英文和半成品标记。
4. 抽取至少 5 个分布在全书的样本与英文对照；高风险学术书增加抽样。

完成标准：没有裁切、重叠、空白异常、孤行标题、乱码或漏章；QA 报告明确通过项、警告和已知局限。

## 判停与恢复

- 文本层严重乱码、OCR 可信度过低、缺页或文件加密：停止翻译，先修复来源。
- 上下文不足以判断术语或代词：标记待核，不猜。
- 结构校验失败：停止后续批次，回到最近一个通过校验的批次。
- 长任务每完成一章就保存中间结果、状态和下一步；允许换会话后从项目清单继续。
- 用户要求出版、公开传播或商业发行时，提醒其确认版权和授权；不要提供法律结论。

## 边界

- 只翻译少量页面或短文时使用普通翻译流程，不启动整书工程。
- 用户要的是摘要、领读或把书蒸馏成技能时，使用相应摘要/蒸馏技能，不制作全译本。
- 不复制或寻找现成受版权保护的正式中文版；只处理用户有权提供和使用的材料。
- 不保证 AI 译稿达到出版社终审标准；出版用途必须加入专业译者、学科专家和版权审校。

## 来源与可信度

本流程来自 2026 年《The Hidden Spring》395 页英文 PDF 全书中译任务：分成 19 个正文/后置部分，交付全书和分章 DOCX、PDF、TXT。已验证的关键经验是段落 ID 防漏译、分章持久化、术语表、注释连续性检查、参考文献保留原文、索引页码说明，以及 DOCX/PDF 全页渲染质检。对其他版式、语言和扫描质量的外推置信度为中高，仍需按来源调整。
