# 翻译规范

1. 总原则

## 总原则

- 完整：不摘要、不删节、不合并掉论证步骤。
- 准确：保留否定、程度、模态、因果与限定范围。
- 自然：译成可持续阅读的现代简体中文，不逐词硬贴。
- 可追溯：所有译文保留稳定段落 ID；解释、疑问和正文分开。
- 一致：术语、姓名、章名、图号和注号跨章节统一。

忠实与自然冲突时，先保证意义和论证关系，再调整句法。不要用更强、更确定或更煽情的中文替代谨慎的英文。

## 试译与风格冻结

在批量翻译前选取：

- 一段作者叙述或案例；
- 一段高度技术化论证；
- 一段含引文、括号或注号的文字；
- 如有图表，再加一段图注。

据此写下并冻结：读者层级、语体、长句拆分尺度、人名规则、核心术语、数字和标点规则。后续如改规则，记录生效章节并回扫旧章。

## 批次提示结构

每批都包含：

1. 全书标题、主题和目标读者；
2. 当前章节名称及其在全书中的作用；
3. 术语表的相关子集；
4. 上一批末段和下一批首段作为只读上下文；
5. 带稳定 ID 的待译段落；
6. 输出约束：只返回 ID 与译文，不输出分析。

批次应在语义边界结束。过长章节可按小节或自然段组拆分，但同一句和同一表格不得跨批。

## 术语与专名

术语表建议字段：

```csv
source,preferred_zh,allowed_variants,forbidden,notes
consciousness,意识,,,全书统一
```

- 术语不是简单词典：记录语境、词性、是否允许变体。
- 人名首次出现可给常用中文名并保留英文；没有可靠译名时保留英文。
- 缩写首次展开，后续遵循原书。
- 不凭印象“纠正”作者的术语；疑似原文错误写入问题表。

## 忠实度复核

逐章抽查以下高风险结构：

- `not`, `unless`, `only`, `at least`, `at most`；
- `may`, `might`, `must`, `should`, `appears`, `suggests`；
- 比较级、最高级和数量范围；
- 长距离代词指向；
- 嵌套引文、括号、破折号和脚注；
- 数字、年份、百分比、单位、公式、图表编号、DOI 和 URL。

润色只能改变表达，不能改变这些逻辑信号。发现同类错误两次以上时，回扫整章而不是只修样本。
