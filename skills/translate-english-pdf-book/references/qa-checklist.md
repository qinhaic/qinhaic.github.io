# QA 清单

## 目录

1. 来源
2. 结构
3. 译文
4. 后置内容
5. 文档与 PDF
6. 交付

## 来源

- PDF 未加密，页数与文件哈希已记录。
- 文本层不是乱码；扫描页已 OCR 并抽查。
- 封面、版权页、目录、正文、注释、参考文献、索引和末页均在处理范围内。
- PDF 页码与书内印刷页码的偏移已记录。

## 结构

- 每个源段落有唯一 ID 和页码来源。
- 译文 ID 无缺失、重复或额外项。
- 章节顺序与原书一致；跨页句已修复。
- 页眉、页脚和页码未误混入正文。

## 译文

- 无空段、整段英文残留、提示词回显、`TODO` 或模型说明。
- 否定、模态、因果、限定和代词指向准确。
- 数字、公式、单位、图号、注号、URL、DOI 和专名可核对。
- 核心术语、章名和人名全书一致。
- 润色后重新做完整性检查。

## 后置内容

- 注释按章连续并能回指正文。
- 参考文献默认保留可检索的原文形式。
- 索引词可译，但页码注明对应英文原版。
- 图表标题、说明、坐标、单位和来源均保留。

## 文档与 PDF

- DOCX 与 PDF 由同一最终正文生成。
- 中文字体可用，粗体/斜体/上下标没有丢失。
- 标题不孤悬页底，段落无大面积孤行寡行。
- 封面、目录、章节首页、图表、注释、参考文献、索引和末页已放大检查。
- 全书页面已用接触表或缩略图扫查；异常页逐页复核。
- PDF 文本可选择复制，未出现裁切、重叠、空白异常或乱码。

## 交付

- 全书与分章文件命名一致、排序明确。
- 提供文件目录、用途说明、非正式译稿声明和已知局限。
- 原书、提取文本、中间译稿和最终稿均未互相覆盖。
- 若用于公开或商业传播，用户已被提醒确认版权和授权。
