# QA 清单

## 目录

1. 来源
2. 结构
3. 译文
4. 后置内容
5. 文档与 PDF
6. 交付

## 来源

- PDF 未加密，页数与文件哈希已记录。
- 文本层不是乱码；扫描页已 OCR 并抽查。
- 封面、版权页、目录、正文、注释、参考文献、索引和末页均在处理范围内。
- PDF 页码与书内印刷页码的偏移已记录。
- 双栏/多栏 PDF 用坐标分栏提取（`extract_columns.py`），栏线 `--mid` 已用 `--analyze`
  确定并记录在 `qa/column-profile.json`。
- 页缘版权水印（APA "intended solely…" 等）已确认非正文，未混入提取文本。

## 结构

- 每个源段落有唯一 ID 和页码来源。
- 译文 ID 无缺失、重复或额外项。
- 章节顺序与原书一致；跨页句已修复。
- 页眉、页脚和页码未误混入正文。
- 双栏页内顺序按阅读方向（第 1 页：眉题→脚注→左栏→右栏；其余页：左栏→右栏）；
  逐页抽查页首和页尾段落的连续性。
- 被拆两行的标题已合并；复合连字符词（self-enhancement 等）已还原。

## 译文

- 无空段、整段英文残留、提示词回显、`TODO` 或模型说明。
- 否定、模态、因果、限定和代词指向准确。
- 数字、公式、单位、图号、注号、URL、DOI 和专名可核对。
- 数字保真：源文用阿拉伯数字时，中文译文的数词要还原为阿拉伯数字
  （"两种"→"2 种"、"三十多岁"→"30 多岁"）；案例/图注等编号标注
  （如 `(Case Study #1)`）不得省略。
- 核心术语、章名和人名全书一致。
- 参考文献段按原文整段保留时，`english_heavy` 校验警告属预期，不阻止通过。
- 润色后重新做完整性检查。

## 后置内容

- 注释按章连续并能回指正文。
- 参考文献默认保留可检索的原文形式。
- 索引词可译，但页码注明对应英文原版。
- 图表标题、说明、坐标、单位和来源均保留。

## 文档与 PDF

- DOCX 与 PDF 由同一最终正文生成。
- 中文字体可用，粗体/斜体/上下标没有丢失。
- DOCX 声明宋体并同时设置 w:ascii / w:hAnsi / w:eastAsia 三个 rFonts；
  无 SimSun 的平台（macOS）渲染时自动替换中文字体属正常，`pdffonts` 确认 CJK 有落地。
- 标题不孤悬页底，段落无大面积孤行寡行。
- 封面、目录、章节首页、图表、注释、参考文献、索引和末页已放大检查。
- 全书页面已用接触表或缩略图扫查；异常页逐页复核。
- 无视觉能力（模型无法读图）时，用渲染 PDF 的文本层做等价质检：`pdftotext -layout`
  检查页数、空页、乱码（`�`/替换字符）、章节标题齐全、关键词覆盖、文末声明在位。
- PDF 文本可选择复制，未出现裁切、重叠、空白异常或乱码。
- LibreOffice 渲染产生的 `.~*` 锁文件已清理。

## 交付

- 全书与分章文件命名一致、排序明确。
- 提供文件目录、用途说明、非正式译稿声明和已知局限。
- 原书、提取文本、中间译稿和最终稿均未互相覆盖。
- 若用于公开或商业传播，用户已被提醒确认版权和授权。
