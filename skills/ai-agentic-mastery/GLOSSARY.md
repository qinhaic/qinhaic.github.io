# 术语表

| 术语 | 本包中的含义 | 不等于 |
|---|---|---|
| agent 工作区 | 能读取/写入持久产物、调用工具并执行多步任务的 AI 环境 | 任何带聊天框的产品 |
| 脚手架 | 上下文、工具、偏好、标准、资料库及路由规则的组合 | 一条超长 prompt |
| 复利 | 本次任务留下的资产让下次任务更快、更稳或能做更多 | 单次回答更长 |
| 上下文资本 | 可维护、可选择、可复用的事实、案例、偏好、标准、流程和产物 | 无差别保存全部聊天记录 |
| 路由 | 根据任务类型选择必要上下文、工具或 Skill | 把所有资料都加载进去 |
| 操作型 Skill | 含流程、工具、标准、边界和上下文要求的可执行能力 | 角色扮演或文风提示词 |
| 问题种子 | 足以开始提出具体问题的最低领域入口 | 专业资格或系统掌握 |
| 学动词 | 用 AI 完成可验收动作并从结果中学习 | 只记产品名、榜单和术语 |
