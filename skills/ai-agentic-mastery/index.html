AI Agent 工作方法

从 Koji 杨远骋与课代表立正的对谈中，蒸馏出四个可触发、可执行、可验证的原子 Skill：让 AI 从一次性回答走向能行动、能留存、能复用的工作系统。

下载完整 Skill 包 观看来源视频 阅读内容精华

核心不是提示词，而是给 AI 修路

高手会为 AI 准备上下文、工具、偏好、标准和资料库，并让每次任务留下可供下一次使用的资产。本包把视频中的观点拆成四种不同触发场景，避免做成一个大而全、只能复述视频的 Skill。

安装方法

  1. 下载并解压完整 Skill 包。
  2. 打开解压后的 skills/ 文件夹。
  3. 将需要的 Skill 目录复制到 ~/.codex/skills/。
  4. 新建 Codex 任务后，用上方示例显式调用，或直接描述符合触发条件的真实问题。

每个 Skill 只有 Markdown 与 JSON，不含脚本、二进制、下载执行或凭据操作。高风险场景均设置了判停或升级条件。

适用边界

  • 不是所有聊天都应迁移成 agent；一次性解释和低摩擦探索仍适合普通对话。
  • 上下文不是越多越好，应按任务选择，并遵守敏感信息最小化。
  • 跨领域广度只负责打开提问入口，不替代医学、法律、财务或工程等专业判断。
  • 视频中的效率倍数与教育预测没有被当作效果承诺。
