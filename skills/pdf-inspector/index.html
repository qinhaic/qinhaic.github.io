精神分析文献阅读

pdf-inspector · 本地快速检查 PDF 文本层、定位扫描页与分栏，并提取文本与 Markdown

Claude Code Skill

用途

阅读精神分析文献 PDF 前，先判断这份 PDF 是文本型还是扫描件、哪些页需要 OCR、有没有分栏和表格；随后本地提取纯文本、Markdown 或带坐标字体的文本。全部本地解析，不联网、不依赖 OCR，单份 PDF 几十毫秒完成。

功能

  • 类型检测：文本型 / 扫描件 / 图片型 / 混合型，附置信度。
  • OCR 路由：列出需要 OCR 的页及原因，快速决定是否走 OCR。
  • 版式识别：定位含表格的页、含分栏的页，提示复杂版式。
  • 提取：纯文本、带标题层级的 Markdown、带坐标与字体的位置化文本。

安装与调用

下载完整 Skill ZIP 查看 SKILL.md

需要 Python 3.11+ 与 pdf-inspector 库（uv venv 安装）。安装后可以对任何 PDF 说：检查这份 PDF 的类型、哪些页需要 OCR、有没有分栏，再提取成 Markdown。

验证记录

用 Baskin-Sommers 等 2014《Empathy in Narcissistic Personality Disorder》双栏 APA 论文（11 页）实测：识别为文本型（置信度 100%），11 页仅 37ms 完成，无需 OCR 的页，准确定位含分栏的页并提取出 18,391 字符的 Markdown。同名 skill 已安装在本机 Claude 环境中。

pdf-inspector 做本地启发式解析，表格与标题识别非完美；复杂版式仍建议抽查原文。
